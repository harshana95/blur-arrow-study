# Blur Arrow Study

A short drawing study. Each photo was taken with a long exposure, so anything that moved left a blur.
Volunteers draw one arrow on each part of the picture that moved; the arrows are used to test
arrow-controlled video generation from a single blurred photo.

Open the page: `index.html` (served by GitHub Pages from the repository root).

What is stored for each volunteer: the arrows, the time they were drawn, a random id kept in the
browser and optional initials. No name, email or address.

The photos come from public research datasets (GoPro, Adobe240, X4K1000FPS and a 2000 fps set) and
are shown here only for this study.
